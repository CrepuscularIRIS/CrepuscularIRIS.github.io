我们被困在一个范式里许久，却一直无法为它命名。每一篇关于神经网络架构的论文——我读了很多，因为我在寻找"正确"的堆叠层方式——都在同一个隐含框架内优化：信息从底部进入，穿过离散的层，从顶部输出。残差连接、密集连接、注意力、甚至 MoE 路由——它们都保留了这种**流水线**的基本图像。我直到最近才意识到：流水线本身是一种建模选择，而非自然法则。真正的问题不是"如何优化流水线中的信息流？"而是"为什么要有流水线？"

这篇文章试图论证：用**内存地址空间**取代流水线。我将残差连接解析为注意力的退化形式，通过一个具体机制——旋转深度嵌入（RDE）——推导出我所称的连续深度记忆网络（CDMN），并论证这种重构与 2025-2026 年兴起的 MoBA/注意力残差系列工作相一致，同时也与海马体记忆系统有着惊人精确的对应关系。

## 第一部分：层的暴政

ResNet 的成功已经形成了一种认知条件反射：残差连接 = 梯度畅通 = 好。这在"为什么深度网络可以训练"的机制层面上是正确的，但这种条件反射已成为一种认知陷阱。它阻止你追问：**层抽象本身**——信息必须在离散、有序的阶段中处理——是否真的在做任何实际工作？

具体来说：在训练好的 ResNet-50 推理时，第 34 层意味着什么？它是第 33 层之后应用的一个函数。移除它会降低准确率。但《残差网络表现得像相对浅层网络的集成》论文（Veit, Wilber, Belongie, NeurIPS 2016）揭示了两个相关现象，我认为值得认真对待：测试时丢弃单个层只会导致性能小幅 graceful 下降，且训练中的梯度贡献主要由远小于名义网络深度的路径主导。这不是严格有序流水线的行为，更接近于共享权重的浅层子网络集成的表现——也就是说，"深度"并没有履行它的承诺。它更像是一个分布式内存，由最终读取阶段进行查询。

PyTorch 和 TensorFlow 的计算图抽象强化了流水线图像：你被迫声明一个 `Sequential` 或模块的有向无环图，而自动微分需要离散节点来进行微分。框架塑造了架构甚至如何被表达。一个数学上便利的流水线——`h_{l+1} = h_l + f(h_l)` 的 Jacobian 是 `I + ∂f/∂h`，特征值聚集在 1 附近，易于分析——这就是被建造的东西，而表达能力问题被 silently 推迟。可优化性先于表达能力，我们最终将可优化的角落误认为是整个设计空间。

## 第二部分：残差是懒惰的注意力

看清问题的最清晰方式是用注意力符号重写残差。

```
标准残差:
    h_{l+1} = h_l + f(h_l)

用显式权重重写:
    h_{l+1} = α_l · h_l + β_l · f(h_l)
    其中 α_l = 1, β_l = 1 (硬编码，不可学习)

作为对比的注意力:
    h_out = Σ_i α_i · v_i,   α_i = softmax(q · k_i)
```

残差连接是注意力的一种退化情况：查询被硬编码为"只看第 l 层"，键集恰好包含一个元素，权重冻结为 1。这是退化情况。这不是比喻——这是关于残差在一般加权和算子中所占子空间的精确陈述。

这种观点隐含的失败模式是具体的：残差假设**正下方的那一层总是包含完全正确的信息**。经验上这是错误的。当第 10 层在推理物体边界时，它有时需要像素级边缘（第 1 层），有时需要语义概念（第 50 层）。它并不 reliably 需要恰好位于第 9 层的东西。这种强制单一源依赖是一种架构假设，而非学习到的行为，其代价是灵活性。

在这种框架下，2025 年的 *MoBA*（块注意力混合）工作——被 Moonshot 推入 ICLR 并随后纳入 Kimi-MoBA 变体——是一种妥协。它允许信息在层**块**内用学习权重进行路由，但块之间恢复了标准残差流水线。MoBA 是脱离单一源层依赖的第一步。*注意力残差*系列工作（2026）走得更远：它将硬编码的 `h_{l+1} = h_l + f(h_l)` 替换为跨所有先前层的学习聚合，将残差本身视为层历史之上的一个小注意力问题。

两者都是部分的。它们仍然将深度视为有序索引。更大的举措是彻底不再将深度视为索引。

## 第三部分：深度就是内存地址

我认为真正改变设计空间的重新定义如下。

**旧本体论：**
- 层 = 处理阶段。
- 深度 = 时间。第 1 层在第 2 层之前发生。
- 前向传播 = 顺序计算。

**新本体论：**
- 深度 = 内存地址。
- 第 1 层和第 100 层都是可寻址的内存槽。
- 前向传播 = 对深度索引内存的一系列内容可寻址的读写。

我认为最有用的类比是从冯·诺依曼架构（程序和数据共享单一总线；指令顺序决定流向）到哈佛架构（程序和数据存在于独立内存中，并行访问，由程序协调读取）的转变。ResNet 是冯·诺依曼的：第 l 层的信息被 `f_l` 的输出 literally 覆盖，残差提供了一条泄漏路径。CDMN 是哈佛的：第 t 层的内容被写入由 t 索引的内存位置，任何后续计算都可以发出查询，从任意地址检索信息，而不受"一步之前发生了什么"的瓶颈限制。

这不仅仅是哲学。现代前沿 LLM 工作已经在朝这个方向迈进。在推理时使用旋转位置嵌入（RoPE）进行*上下文级*检索——其中特定的头模式被训练将相对位置视为可检索状态的索引——是我想在**深度轴**上应用的相同机制。如果位置嵌入是 token 维度的内存地址，那么深度嵌入应该在深度维度上发挥相同的作用。

因此提出了这个机制。

## 第四部分：旋转深度嵌入（RDE）

核心对象是一个嵌入，它将连续深度坐标 $t \in [0, 1]$ 映射为应用于该深度状态向量的旋转。它在机械上与 RoPE 相同，但坐标是深度而非 token 位置。

```python
import torch
import torch.nn as nn

class RotaryDepthEmbedding(nn.Module):
    """将深度坐标 t ∈ [0, 1] 编码为特征空间中的旋转。
    这使得深度成为可检索的索引，而非顺序阶段。
    """
    def __init__(self, dim: int, base: float = 10000.0):
        super().__init__()
        assert dim % 2 == 0, "dim 必须为偶数以支持配对旋转"
        self.dim = dim
        inv_freq = 1.0 / (base ** (torch.arange(0, dim, 2).float() / dim))
        self.register_buffer("inv_freq", inv_freq)

    def forward(self, depth_coords: torch.Tensor):
        # depth_coords: (B,) 每个样本的标量深度。
        # 返回 cos/sin，形状为 (B, 1, dim/2)，因此它们在 token 轴上广播。
        angles = depth_coords.unsqueeze(-1) * self.inv_freq  # (B, dim/2)
        cos = torch.cos(angles).unsqueeze(1)                 # (B, 1, dim/2)
        sin = torch.sin(angles).unsqueeze(1)                 # (B, 1, dim/2)
        return cos, sin

    @staticmethod
    def apply_rotation(x: torch.Tensor, cos: torch.Tensor, sin: torch.Tensor):
        # x: (B, N, D); cos/sin: (B, 1, D/2) — 在 tokens 上广播。
        x1, x2 = x[..., ::2], x[..., 1::2]
        rotated = torch.stack([x1 * cos - x2 * sin,
                               x1 * sin + x2 * cos], dim=-1)
        return rotated.flatten(-2)
```

具体来说，这带来了两个好处：

1. **深度距离以相位衡量，而非层数。** 深度 $t_1$ 和 $t_2$ 处的两个计算具有相对旋转 $\theta(t_2 - t_1)$，这意味着即使它们的层索引相距很远，它们也可以"相位对齐"（因此可通过匹配查询检索）。第 1 层和第 100 层如果映射需要，可以处于相同的深度相位。

2. **深度变得可微分。** 你可以学习每个块在 $[0,1]$ 轴上的位置，而不是硬编码它。这将"多少层？"从超参数转变为学习容量分配的问题。

完整的 CDMN 层将 RDE 与检索算子结合，而非残差。更新在数学层面上是：

```
h(t) = h(t)  +  OutProj(  Σ_i  α_i(t)  v_i  )
其中
    α_i(t) = softmax_i(  RotateByPhase(q(t), θ_t)
                       · RotateByPhase(k_i,   θ_{t_i}) / √d )
    q(t)   = Q(h(t)),      k_i = K(landmark_states_i)
    v_i    = V(landmark_states_i)
    θ_t    = 深度坐标 t ∈ [0, 1] 的角度嵌入
```

以及作为最小参考实现的伪代码（为可读性简化了形状处理；生产版本对地标进行批处理、缓存旋转的键，并使用 Flash-Attention 内核）：

```python
class CDMNLayer(nn.Module):
    def __init__(self, dim: int, num_landmarks: int = 8):
        super().__init__()
        self.dim = dim
        self.rde = RotaryDepthEmbedding(dim)
        # 学习的内存槽，每个绑定到学习的深度坐标。
        self.landmark_depths = nn.Parameter(torch.linspace(0, 1, num_landmarks))
        self.landmark_states = nn.Parameter(torch.randn(num_landmarks, dim) * 0.02)
        self.q_proj = nn.Linear(dim, dim)
        self.k_proj = nn.Linear(dim, dim)
        self.v_proj = nn.Linear(dim, dim)
        self.out_proj = nn.Linear(dim, dim)

    def _rotate_single(self, x_vec: torch.Tensor, depth: torch.Tensor) -> torch.Tensor:
        # x_vec: (*, D); depth: 标量张量 -> 返回 (*, D)
        angles = depth.view(-1, 1) * self.rde.inv_freq       # (1, D/2)
        cos, sin = torch.cos(angles), torch.sin(angles)       # (1, D/2)
        x1, x2 = x_vec[..., ::2], x_vec[..., 1::2]
        rot = torch.stack([x1 * cos - x2 * sin,
                           x1 * sin + x2 * cos], dim=-1)
        return rot.flatten(-2)

    def forward(self, x: torch.Tensor, current_depth: torch.Tensor) -> torch.Tensor:
        # x: (B, N, D); current_depth: [0, 1] 范围内的标量张量。
        cos_q, sin_q = self.rde(current_depth.expand(x.size(0)))
        q = RotaryDepthEmbedding.apply_rotation(self.q_proj(x), cos_q, sin_q)

        # 每个地标由其*自身*的学习深度坐标旋转。
        rotated_ks = torch.stack([
            self._rotate_single(self.k_proj(self.landmark_states[i]),
                                self.landmark_depths[i])
            for i in range(self.landmark_states.size(0))
        ], dim=0)                                             # (L, D)
        v = self.v_proj(self.landmark_states)                 # (L, D)

        # 缩放点积检索: (B, N, D) @ (D, L) -> (B, N, L)
        attn = torch.softmax(q @ rotated_ks.T / (self.dim ** 0.5), dim=-1)
        retrieved = attn @ v                                   # (B, N, D)
        return x + self.out_proj(retrieved)
```

关键结构特性：当前深度的状态被允许从由学习地标深度索引的内存中**检索**，而不是被迫只读取其直接前驱。残差作为懒惰注意力的角色转变为作为检索的注意力。

## 第五部分：三层粒度金字塔

没有粒度层级的 CDMN 会坍缩为单一 Massive 注意力操作，这在计算上不可行且在经验上不稳定。缓解措施——同时也恰好 mirrors 海马体-皮层层级——是一个三层金字塔：

- **粗粒度（地标级别，约 4-8 个槽位）。** 语义路标：边缘检测完成、部件组装完成、对象识别完成。类似于整合的皮层记忆。
- **中粒度（块级别，O(√n) 个槽位）。** 共享 RDE 坐标的层自适应块。类似于短期皮层回路。
- **细粒度（token 级别，标准注意力）。** 每个 token 的精度；精确信号存活的路径。类似于海马体高分辨率轨迹。

任何深度的查询都被允许从任何级别检索，但默认是 coarse-to-fine：先检查地标（廉价），然后是块（中等），最后是 tokens（昂贵）。这是"自适应粒度"机制，匹配海马体文献中整合（低成本、低保真度回忆）与从 HPC 检索（高成本、高保真度）之间的权衡。

## 第六部分：三维质疑法

有了这个框架，对任何提议架构的实用批评可以归结为三个问题。我发现这个框架在审查架构论文时很有用——它产生具体的反对意见，而非模糊的美学反应。

**维度 1：交互阶数。** 架构原生编码的最高阶关系是什么？MLP 是一阶（孤立单元）。CNN 和注意力是二阶（成对）。真正的群体级现象——场景理解、多智能体协调、多区域神经整合——需要超图级交互，而任何标准架构都无法在不加事后 glue 的情况下编码它们。

**维度 2：均匀性假设。** 架构强制哪些轴被均匀处理？ResNet 强制均匀的深度累积。标准注意力强制每层内均匀的成对交互。比"如何训练这个？"更好的问题是"我在哪些维度上支付均匀性税，而我的任务实际上需要该轴是均匀的吗？"

**维度 3：可分离性假设。** 哪些轴被强制分开处理？深度 vs 宽度、空间 vs 通道、模态 vs 模态。每一次分离都是跨轴信息不值得显式建模的承诺。有时这是对的。当它是错的时，它非常错，进步通常来自重新纠缠这两个轴——视觉-语言模型中的跨模态注意力、ConvNeXt 风格设计中的通道-空间混合、以及更广泛超图卷积文献都以不同方式使这一点具体化。

## 第七部分：海马体对应

神经科学平行不是装饰性的；它是为什么我认为设计是正确的理由。

海马体为生物大脑解决了内存寻址问题。三个特征明确的子回路清晰地映射到 CDMN 组件：

| 神经回路 | 功能 | CDMN 类比 |
|---|---|---|
| 齿状回 (DG) | 模式分离——使相似输入产生可区分的表征 | 具有稀疏、近正交码的输入编码层 |
| CA3 递归网络 | 模式完成——从不完整线索恢复完整记忆 | 从地标槽位进行的基于注意力的检索 |
| CA1 时间细胞 | 顺序/时间编码 | RoPE 风格的深度位置编码 |

两个具体现象值得标记，因为它们暗示了具体的架构约束，而非模糊的灵感：

**Theta 周期相位编码。** 海马体 theta 振荡（4-8 Hz）将空间和记忆信息组织到相位窗口中，每个周期大约有 4±1 个可区分项（与 Miller 定律一致）。这是基于相位索引离散记忆内容的直接神经证据——这正是 RDE 在硅中所做的。

**稀疏-密集互补学习。** DG-CA3 分工（稀疏正交化，然后密集自联想检索）对应于特定的架构选择：稀疏输入编码不是性能优化；它是稳定检索的前提。在没有地标写入步骤稀疏性的情况下训练的 CDMN 应该遭受灾难性检索干扰——这是一种可预测、可测试的失败模式。

## 第八部分：与 MoBA、注意力残差和 Muon 的关系

CDMN 并不反对最近的架构工作；它吸收并外推了它们。

- **MoBA** 允许块内的稀疏路由。CDMN 说：让块边界本身被学习（通过 RDE），并让路由跨越整个深度轴。
- **注意力残差** 用跨所有先前层的学习聚合替换硬编码的 `+ f(h_l)`。CDMN 说：聚合是对内存可寻址深度的检索，而非对层索引的加权和。
- **Muon / Moonlight** 优化器是关于如何稳定地训练激进参数化的层。这些技术应该直接移植到 CDMN，因为可微分结构非常相似——你仍然在训练具有平滑、良好条件 Jacobians 的网络，只是形状重塑了。

历史脉络清晰可见：

```
固定 3×3 CNN (硬结构)
    ↓
ResNet (软旁路: 层 l+1 可直接看到层 l)
    ↓
DenseNet (任意到任意，但无选择)
    ↓
MoBA / 注意力残差 (块内的学习选择)
    ↓
CDMN (连续选择; 深度变为地址)
```

每一步都在软化一个硬约束。CDMN 软化了最后一个：整数值的层索引。

## 第九部分：首先测试什么

如果没有具体的实验预测，这将是 vaporware。三个第一阶段实验，每个都小到可以在单个 GPU 上运行：

1. **RDE 作为检索 vs. CIFAR-10 / ImageNet-32 上的标准残差。** 将 RDE 索引的检索插入 ResNet-18 替代残差；报告收敛速度、最终准确率、梯度范数稳定性。预测：最终准确率 comparable，但达到终端性能 90% 所需的 epochs 更少，因为深度索引检索消除了冗余的顺序处理。

2. **深度相位对齐可视化。** 训练带有 RDE 的 ResNet-18，然后绘制学习的深度坐标及其相对相位。预测：自然聚类为 3-5 个"深度区域"，与三层粒度层级一致。

3. **长程依赖任务上的地标消融（例如 Long Range Arena）。** 预测：带有少量精心放置地标的小型 CDMN 在信息必须跨越长距离深度存活的任务上，匹配深得多的标准 Transformer。

如果 H1 或 H2 失败，那么框架在根本层面上就是错误的，我需要重新审视它。如果 H3 失败，那么内存作为地址的隐喻是正确的，但具体机制是错误的——需要不同的检索算子。

## 结语：从管道到交换机

我主张的转变是从管道到交换机。管道将数据通过有序阶段移动，接受串行依赖的成本；交换机让数据被路由到一个空间，其中任何点可以随时从任何其他点查询。ResNet 是一个打了补丁的管道（残差是一个旁通阀）；MoBA 是仍在串行管道内的部分交换机；CDMN 是深度轴完全从索引轴解绑的交换机。

让你从一种走向另一种的元认知转变是：注意到每当基础设施（自动微分、计算图、工具）使一种设计容易而另一种设计困难时，你基于该基础设施进行的理论推理就会继承其偏见。"残差有效"是真的。"残差是**正确**的深度布线方式"是一个更强的主张，我们接受它是因为我们无法轻松构建替代方案。现在替代方案是可建造的。是否值得建造是一个经验问题，有清晰的实验预测——这是这条思考路线诚实收尾的地方。
