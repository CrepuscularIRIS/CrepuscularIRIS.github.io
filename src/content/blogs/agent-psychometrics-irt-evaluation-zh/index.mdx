当一个 Agent 在 SWE-bench Verified 上失败时，排行榜只告诉你一件事：系统得分 X%。它不会告诉你失败的原因是模型理解错了任务、脚手架给模型喂了错误上下文、工具链在模型拿到第二次机会前就崩溃了，还是基准本身包含的题目本身就描述不清——换谁来都解不出来。四种失败模式在结果矩阵里显示为同一个红色格子。

这是一个诊断问题，在教育测量领域以不同形式已经存在了 70 年。当一个学生 SAT 考砸了，你不能直接下结论说学生能力弱、题目太难，还是测试本身有问题——你需要一套能把这些因素分离出来的模型。教育工作者使用的工具叫 Item Response Theory（IRT）。2026 年 4 月的一系列工作提出：将同一套方法论移植到 Agent 基准测试上，就能得到一种有原则的方式来把 Agent 失败归因于模型、脚手架或题目本身。

我打算认真审视这个论证，拆解 IRT 应用到 Agent 评测矩阵时实际做了什么，并解释为什么它给出的答案比排行榜上的单一通过率数字更有用。

## 通过率隐藏了什么

来看一个具体例子。两个 Agent 系统在 SWE-bench Verified（一个包含 500 道 GitHub Issue 的子集）上评测：

| 系统 | 通过率 |
|------|--------|
| Claude Opus 4.6 + ReAct 脚手架 v3 | 62% |
| GPT-5.4 + 自定义多轮脚手架 | 59% |

粗浅的解读是 Claude + ReAct 领先 3 个百分点。但这个解读忽略了三个问题：

1. **脚手架互换**：如果把 Opus 4.6 放到 GPT-5.4 的脚手架后面跑，分数会变——而这跟模型能力毫无关系。
2. **题目难度不均匀**：一个系统通过了 62% 的题目，可能解出了所有简单题而没有一道难题，也可能是难度分布均匀的混合。两种系统性质完全不同。
3. **基准饱和度的协变**：通过率超过 70% 以后，简单题目主导了信号。82% 到 85% 的 3 分差距与 32% 到 35% 的 3 分差距含义完全不同。

排行榜把所有三种因素压缩成一个数字——这相当于只报告学生 GPA，却不告诉你他修了哪些课。

## Item Response Theory 一页通

IRT 的核心假设是：每道题目有潜在属性（难度），每个受测者有潜在能力（ability），而在这道题上答对的概率由两者共同决定。最简单的形式——Rasch 模型——每道题一个参数（难度 $b_i$），每个人一个参数（能力 $\theta_p$）：

$$
P(\text{通过}_{p,i}) = \frac{1}{1 + e^{-(\theta_p - b_i)}}
$$

解读很清晰：如果 $\theta_p > b_i$，受测者很可能通过题目 $i$；如果 $\theta_p < b_i$，很可能失败。差值 $\theta_p - b_i$ 用同一单位（logits）度量，所以你可以直接比较能力分数和题目难度。

双参数模型（2PL）增加了区分度参数 $a_i$，捕捉题目区分能力高低的锐度：

$$
P(\text{通过}_{p,i}) = \frac{1}{1 + e^{-a_i(\theta_p - b_i)}}
$$

高区分度题目意味着微小的能力差距就能产生很大的概率波动——这类题目对于排序处于该能力区间的系统特别有价值。低区分度题目无论能力高低，都有一定随机性通过或失败——这是题目可能被污染的信号。

三参数模型（3PL）增加了猜测参数 $c_i$，用于那些低于能力水平的系统也有非零概率靠运气通过的题目。SWE-bench 中包含trivial fix（改个变量名、加一行 import）的题目就像高猜测题目——任何系统只要尝试做点什么，就有一定概率歪打正着。

三种模型都用最大似然法从通过/失败矩阵中拟合。输出的是潜在参数——诊断能力就来自这里。

## Agent 版新变量：两个潜在能力，不是一个

教育场景中每道题只有一个参与者：学生。Agent 系统有两个：LLM 和脚手架。如果用普通 IRT 模型把整个 Agent 当做一个参与者来拟合，你会得到每个（模型，脚手架）组合的一个能力分数——又回到了排行榜问题。

改进方案是把能力项做因式分解：

$$
\theta_{p} = \theta_{\text{LLM}}(p) + \theta_{\text{scaffold}}(p) + \epsilon_{p}
$$

其中 $p$ 现在索引一个（模型，脚手架）组合，$\epsilon_p$ 捕捉不能加性分解的组合特定交互效应。可识别性需要标准约束：将 $\theta_{\text{LLM}}$ 和 $\theta_{\text{scaffold}}$ 中心化使其和为零（或者固定一个模型和一个脚手架作为参照），并用先验或 L2 惩罚对 $\epsilon_p$ 做正则化，防止它吞掉所有方差。如果你让 $M$ 个模型跑在 $S$ 个脚手架上面对同样的 $N$ 道题，通过/失败张量是 $M \times S \times N$——只要有足够的交叉覆盖（不是每个模型都跑每个脚手架，但重叠足够使各项可识别），就有足够的自由度来识别两个潜在能力向量和交互项。

拟合结果产出三个有用的量：

- $\theta_{\text{LLM}}$ per 基础模型——"这个模型有多聪明"的数字，已剥离脚手架效应。
- $\theta_{\text{scaffold}}$ per 脚手架——"这个脚手架增加了多少能力"的数字，已剥离模型效应。
- $b_i, a_i, c_i$ per 基准题目——每道任务的难度、区分度和可猜测性。

现在你可以问出比排行榜更尖锐的问题：当模型固定时，脚手架 A 比脚手架 B 更好吗？脚手架的提升在不同难度题目上均匀吗，还是脚手架 A 只在最难的题目上有帮助？模型 X 是否有任何脚手架都无法突破的潜在能力天花板？

## 一个拟合示例

简化版的分析：三个模型，三个脚手架，200 道题。拟合出的能力如下：

| 模型 | $\theta_{\text{LLM}}$ |
|------|----------------------:|
| Opus 4.6 | +1.20 |
| GPT-5.4 | +0.85 |
| Gemini 3.1 Pro | +0.62 |

| 脚手架 | $\theta_{\text{scaffold}}$ |
|-------|---------------------------:|
| 自定义 Agent 脚手架 v7 | +0.70 |
| ReAct v3 | +0.30 |
| Bare 单轮 | +0.00 |

logits 可加性解读：最好和最差脚手架之间的差距（+0.70）几乎等于最好和最差模型之间的差距（+0.58）。这给工程社区两年来定性主张的观点提供了定量支持：脚手架的提升几乎等于模型升一档。

更重要的是，你可以把 $P(\text{通过})$ 画成题目难度 $b_i$ 的函数，对每个组合画出一条曲线。曲线告诉你每个组合在哪个难度上达到平台期。裸 Opus 4.6 的通过率曲线在 $b_i = 0.5$ 左右趋于平缓——说明比这更难的题目光靠模型本身是解不出的。加上自定义脚手架后，曲线在 $b_i = 1.3$ 处才平缓。脚手架把可解边界往前推了。

## 检测污染题目

IRT 的第二个用途是清洗基准。高能力系统通过、低能力系统失败的题目具有高区分度和低拟合残差。所有系统无论能力高低都通过的题目区分度低——要么太简单，要么是测量artifact（测试文件里意外包含了预期修复方案、自动化评分器接受空输出）。

标准流程是心理测量题库建设的常规操作：

1. 在全部题目上拟合 IRT 模型。
2. 计算每道题目的 infit 和 outfit 统计量（观测通过率与预测通过率之间的标准化残差）。
3. infit > 1.3 或 outfit > 1.5 的题目标记为拟合不佳——它们的行为不符合模型预测。
4. 人工审查被标记题目。有些是污染题。有些是异常的但合法题目。IRT 标记是人工审核的触发器，不是自动删除指令。

应用到 SWE-bench Verified，这套流程应该能筛出你在任何存在测试泄露污染的基准上都能看到的模式：测试文件意外编码了预期修复方案的题目会导致跨模型接近均匀的通过率，进而区分度低。SWE-bench Pro 污染分析（见[那篇博文](/blog/swebench-pro-contamination-crisis)）通过直接检查识别出了这类问题；IRT 靠分布视角捕获相同信号，不需要检查环节。

对基准作者的影响：对题目做静态通过率排名（"第 17 题最难，第 42 题最简单"）不如基于 IRT 的排名信息量大，因为后者的难度估计来自模式而非均值表现——对哪套系统恰好被评测过是不变的。

## 实现：最小可运行示例

数学部分已有成熟的 Python 库支撑。下面是一个说明性骨架（生产代码需要收敛检查、正则化和完美响应者处理——这里省略）：

```python
import numpy as np
from scipy.optimize import minimize

def fit_2pl(responses: np.ndarray) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    """
    通过联合最大似然拟合 2 参数 logistic IRT 模型。

    Args:
        responses: (P, I) 二值矩阵 — 受测者 p 在题目 i 上的结果。
    Returns:
        theta: (P,) 能力估计
        b: (I,) 题目难度
        a: (I,) 题目区分度
    """
    P, I = responses.shape

    def nll(params):
        theta = params[:P]
        b = params[P:P + I]
        a = np.exp(params[P + I:])  # 保证区分度为正
        logit = a[None, :] * (theta[:, None] - b[None, :])
        p = 1.0 / (1.0 + np.exp(-logit))
        p = np.clip(p, 1e-9, 1 - 1e-9)
        ll = responses * np.log(p) + (1 - responses) * np.log(1 - p)
        return -ll.sum()

    x0 = np.concatenate([
        np.zeros(P),
        np.zeros(I),
        np.zeros(I),
    ])
    res = minimize(nll, x0, method="L-BFGS-B")
    theta = res.x[:P]
    b = res.x[P:P + I]
    a = np.exp(res.x[P + I:])
    # 中心化 theta 防止可识别性漂移
    theta = theta - theta.mean()
    return theta, b, a
```

对于 LLM/脚手架分解，把每个（模型，脚手架）组合当作一个独立"受测者"，把估计出的 $\theta$ 值对模型和脚手架的 one-hot 特征做回归。残差就是交互项 $\epsilon$。

实践中，用 `pyirt`、`mirt`（R via rpy2）或 `girth` 做生产分析——它们处理上述骨架没有覆盖的数值边界情况（完美响应者、零方差题目）。要点不是重新发明心理测量推断，而是把它应用到正确的数据结构上。

## 这会如何改变 Agent 评测

用这种方式处理基准，有三个实践层面的后果。

**第一**，报告应该包含带置信区间的能力估计，而不只是通过率。$\theta = 1.2 \pm 0.3$ 和 $\theta = 1.2 \pm 0.08$ 的 Agent 含义完全不同。方差对稳定性判断至关重要。

**第二**，基准设计应该以信息量最大化为目标。$b_i$ 处于当前系统能力前沿的题目贡献最多信息；人人通过或无人通过的题目几乎不贡献任何信息。基准作者目前靠随意挑选题目。IRT 提供了一个有原则的选择标准：目标能力区间内预期通过概率在 0.3 到 0.7 之间的题目。

**第三**，当你把模型换到同一个脚手架后面时，预期提升是可以从能力分解预测的。如果脚手架 A 有 $\theta_{\text{scaffold}} = 0.7$，你的新模型 $\theta_{\text{LLM}}$ 比旧模型高 0.3，你应该预测组合能力提升 0.3（不是 1.0，也不是零）。实证偏离这个预测是诊断信号——提升小于预期说明存在交互效应，大于预期说明新模型解锁了旧模型靠脚手架无法触达的能力。

## 值得指出的注意事项

IRT 假设局部独立性——即题目回答在以能力为条件时跨题独立。Agent 基准常常违反这个假设，因为连续任务可能共享代码、共享环境或错误累积。违反假设会削弱模型但不会推翻方法；只是意味着 $\epsilon$ 权重更大，分解结果噪声更多。

IRT 还假设能力是一维的。Agent 可能在重构任务上很强但在缺陷定位上很弱——把两者压缩成一个 $\theta$ 会丢失信息。多维 IRT（MIRT）是标准解决方案，在教育领域已经用了几十年。代价是更大的参数空间，需要更多数据来识别。

最后，IRT 是测量模型，不是因果模型。它告诉你脚手架 A 对能力贡献了 $+0.7$，但不告诉你*为什么*——是来自更好的上下文组装、恢复循环、验证环节，还是其他什么。把测量结果连接到机制需要在心理测量分析之上叠加消融实验。
