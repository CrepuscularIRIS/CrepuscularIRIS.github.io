# FingerTip 20K：让手机 Agent 学会预判你要做什么

**原文标题：** FingerTip 20K: A Benchmark for Proactive and Personalized Mobile LLM Agents  
**作者：** Qinglong Yang 等  
**发表：** OpenReview / 2026  
**链接：** [OpenReview](https://openreview.net/forum?id=n3iFV0gLMc)

---

## 一句话摘要

FingerTip 20K 基于 **20,000 条真实用户 Android 操作记录** 构建——它不只记录"用户做了什么"，更捕捉"什么情境下用户倾向做什么"，从而训练手机 Agent 在恰当的时机主动推荐任务，并根据个人习惯定制执行路径。

---

## 为什么选这篇

大多数手机 Agent 论文把手机当成一个"被动工具"：你下达指令，它执行。这是最简单的版本。

真正困难的问题是：**Agent 怎么在你开口之前就知道你需要什么？** 时间、地点、最近打开的应用、重复出现的行为模式——被动等待指令的 Agent 对这些信号视而不见，主动型 Agent 则应该加以利用。

第二个维度同样重要却常被忽视：即使两个用户要求做同一件事，过程可能完全不同。一个用户喜欢短平快的路线，另一个习惯在处理正事之前先查一遍邮件。好的 Agent 应该适应这种差异。更进一步，伟大的 Agent 应该在"没有被告知"的情况下自己学会适应。

FingerTip 20K 是首个在真实使用场景中大规模捕捉这两个维度的数据集，而非通过脚本生成合成任务。无论这份基准最终能否经受检验，它提出的目标——**主动推荐 + 个性化执行**——是手机 Agent 真正应该前进的方向。

---

## 核心方法（3 分钟版）

论文的核心洞察非常清晰：现有手机 GUI Agent 本质上都是被动的。它们等待指令，不会查看时间、读取位置，也不会注意到"每周四上午 9 点这个用户都会打开报销应用"这一规律。

要训练一个能弥合这一差距的 Agent，首先需要数据——而且是真实反映人类如何使用手机的数据。

**他们收集了什么。** 作者在真实 Android 设备上搭建了持续数据采集管道，捕捉跨日常应用的多步骤交互序列，最终得到 **20,000 条独特的人类演示记录**。这个规模在现有手机 Agent 基准数据集中是领先的。更关键的是：这不是众包工人在完成玩具任务，而是真实用户在真实场景下的操作记录。

**数据集支撑的两个子任务：**

1. **主动任务推荐。** 给定用户当前情境（时间、地点、最近应用使用情况等），预测用户接下来可能想做什么，并主动呈现。类比来说：Agent 发现现在是工作日上午 8:45，用户刚把车挂入 D 档——它主动建议启动导航，目的地是用户通常的通勤路线。

2. **个性化执行轨迹。** 两个用户都说"给妈妈发条消息"。第一个用户的路径是：打开默认短信应用 → 查找联系人 → 发送。第二个用户总是先切换到第三方应用再发送。Agent 应该学会并复现**那个特定用户的风格**，而非一个虚构的平均路径。

**关键设计决策。** 与其脚本化任务或生成合成轨迹，作者选择在真实 Android 交互中植入采集工具，被动记录演示数据。这种做法难度更高，但产出的数据才能真实反映人类行为，而不是研究者假设的人类行为。

## 关键结果

源笔记中未包含具体量化指标（成功率、准确率或对比基线）。论文目前能够确认的内容如下：

| 维度 | 详情 |
|---|---|
| 数据集规模 | **20,000** 条真实人类演示 |
| 采集方式 | 真实用户 Android 交互日志（非合成任务） |
| 任务类型 | 跨日常应用的多步骤序列 |
| 基准测试目标 | 主动推荐 + 个性化执行 |
| 评估指标 | **源笔记中未提供具体数据** |

对于基准测试论文而言，最关键的部分是"现有 Agent 在这个基准上的表现表格"。源笔记中缺失这一信息，构成了显著的评估盲区。

## 局限与未回答的问题

源笔记本身不完整，以下判断存在不确定性，但以下几个问题值得关注：

**没有量化结果。** 基准测试论文最重要的贡献是一张表格，展示现有 Agent 在该基准上的表现。缺少这个，就无法判断 FingerTip 20K 究竟是极具挑战性还是轻而易举。

**数据集是否公开尚不明确。** 20K 条演示是一笔不小的资源。它是否公开？以什么许可证开放？如果数据不公开，基准就无法被社区复现或拓展——而这恰恰是基准存在的意义。

**"主动"的定义需要更精确。** 主动推荐要求 Agent 从情境中推断意图。论文需要明确：推荐应该在任务实际发生前多久触发？提前 30 秒和提前 30 分钟是完全不同的能力要求。

**用户同意与隐私。** 在真实 Android 设备上持续记录交互数据，隐私问题不言而喻。论文可能有所论述（2026 年的隐私规范更严格），但源笔记未提供任何细节。

**跨设备类型的泛化能力。** 数据来自 Android，习得的行为能迁移到 iOS 或平板吗？这对实际部署至关重要。
