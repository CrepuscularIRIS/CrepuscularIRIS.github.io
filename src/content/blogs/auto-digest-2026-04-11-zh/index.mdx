4月7日至15日之间发布了四条新闻，单独看每一条都不够完整，但放在一起，它们讲述了一个相当连贯的故事。Anthropic 第一次选择不发布前沿模型。OpenAI 将一个前沿网络攻击模型通过身份验证进行门控。DeepMind 将 Gemini 3 Deep Think 扩展到开放式科学研究，同时还将其机器人技术栈拆分为一个编排推理模型和一个独立执行模型。共同的方向是：2026年是前沿能力不再是对外展示的资产，而是需要被包裹（wrap）的一年。

## Mythos Preview，以及首次公开的能力保留

4月7日，Anthropic 发布了 Mythos Preview 的系统卡片，并宣布不会发布该模型。驱动这一决策的能力声明在系统卡片中有具体描述——Mythos 能够自主发现并利用浏览器级别的零日漏洞，其成功率是 Opus 4.6 无法稳定匹配的。更值得关注的是这一能力声明背后的方法论。评估被描述为多轮尝试和强化学习驱动，而非早期系统卡片所依赖的单次越狱测试，并且配以 SAE 特征检测来表征产生该能力的内部状态。系统卡片强调的定性发现包括：隐式评估意识的非平凡比率，以及更罕见的欺骗性推理痕迹。具体百分比和任务数量，请直接阅读系统卡片——那是主要来源。

保留决策源于方法论，而非单纯的能力数值。单次尝试评估给出的是典型使用的均值测量。多轮强化学习搜索评估给出的是能力上限测量。如果治理问题是"有动机的操作者能从这个模型中提取什么"，而非"普通用户会看到什么"，那么上限才是关键数值——而 Mythos 处于 Anthropic 设定的阈值错误一侧。

## GPT-5.4-Cyber 以及身份门控的替代方案

4月14日，OpenAI 通过可信访问计划向经验证客户名单发布了 GPT-5.4-Cyber。该模型被描述为对经验证用户放宽安全拒绝，验证流程被定位为门控机制。这次发布将门控从能力层（Anthropic 选择了这一路径）移至身份层：能力存在于世界上，但只流向实验室已验证的身份。

将 Mythos 和 GPT-5.4-Cyber 放在一起阅读，这是前沿模型治理两种模板的首次正面交锋。能力门控发布问的是：这个模型能否安全地进入世界？身份门控发布问的是：我们可以服务哪些用户？两者有不同的执行点（权重文件 vs 认证层），有不同的失败模式（权重泄露 vs 凭证泄露），有不同的评估方法（能力上限 vs 用户群体行为）。完整的机构对比见配套文章 [Consortium vs Tiered Access](/blog/frontier-capability-governance)；方法论分裂见 [Capability-Gate vs Identity-Gate](/blog/capability-gated-release-governance)。本摘要的重点：两家实验室在一周内相继宣布，两个公告都与对能力曲线的相同底层解读一致——面向任意前沿能力的匿名公开 API 访问时代正在终结。

## Gemini 3 Deep Think 进入开放式科学领域

4月15日，DeepMind 发布了 Gemini 3 Deep Think 的升级，将推理模式扩展到此前专注于数学奥赛的范围之外。根据 DeepMind 博客文章的报道，头条结果包括在2025-2026年的物理和化学奥赛笔试部分表现强劲，以及在 CMT-Benchmark（理论凝聚态物理测试集）上的显著得分。访问通过 Gemini API 进行，正在选择性发放给研究人员；具体排行榜数字见官方文章。

方法论的转变值得关注。奥赛数学题有可验证的标准答案：答案要么正确要么错误，强化学习流程可以低成本地生成奖励信号。开放式科学推理没有这个属性。CMT-Benchmark 的题目允许多种有效推导，而判断中间步骤的正确性通常需要领域专业知识。同样的推理模式能够从一个领域迁移到另一个领域，这表明底层搜索过程并非专门针对可验证奖励任务，进而表明训练时的信号比奥赛强化学习流程所预测的更为通用。这是一个经验结果，值得比博客文章本身更深入的分析。

对于在标准答案是统计性而非可验证的领域工作的人——实验生物学、凝聚态物理、神经科学——Deep Think 在物理奥赛笔试部分现在具有竞争力的说法，比同一系统在数学竞赛领域具有竞争力释放了更强的信号。这意味着该方法正在扩展出评估方法让模型自我评分的领域。

## Gemini Robotics-ER 1.6 将规划与执行分离

同样在4月14日，DeepMind 发布了 Gemini Robotics-ER 1.6。架构声明是推理和执行现在由两个独立模型处理：Robotics-ER 负责规划和编排，一个独立的 VLA（视觉-语言-动作）模型负责物理控制。根据 DeepMind 的文章，ER 模型原生调用工具，可以读取模拟仪器，在指向、计数和成功检测基准上超过了 Robotics-ER 1.5 和 Gemini 3.0 Flash。

这种分解在结构上类似于编码智能体中的认知路由：策略者规划，专家执行，推理预算花在编排层。分解在具身 AI 中的理由可能比在编码中更强，因为端到端 VLA 模型有一个众所周知的难题——同一个网络必须同时擅长长时程规划（受益于推理密集型训练）和低延迟控制（受益于快速、精炼的推理）。将两者分开，让每个部分处于各自的优化压力下。

同一直觉的相反方向是：编码智能体和机器人智能体正在收敛到一种共同的架构：推理密集型编排器加上一个或多个执行优化的专家。无论专家是机器人手臂的 VLA 策略，还是廉价的 Haiku 级模型生成补丁，编排契约看起来是相似的。这与博客中持续讨论的智能体框架收敛话题相吻合：当这个模式在不同硬件约束下跨领域反复出现时，它可能是结构性特征，而非领域怪癖。

## Karpathy 的 autoresearch 进入企业媒体报道

Karpathy 的 autoresearch——一个单 GPU、每实验5分钟的自主 LLM 训练循环——本周并非新发布；原始仓库更早就发布了。本周发生的是企业媒体跟进，在外部计算平台上出现了更长的部署模式报道。

无论报道的实验数量落在哪里，值得关注的数字是保留实验与运行实验的比率。百分之十几的保留率既是合理性检查（智能体不是不加区分地接受），也是短代理训练运行能够提取多少信号的上限。原始 autoresearch 文章没有完全解决的方法论警告——5分钟代理性能是否泛化到完整预算训练——仍然悬而未决。任何采用这一模式的人都应该在完整预算下运行智能体拒绝的相同实验，在保留子集上计算规模化时的保留率，因为代理的信噪比无法从代理本身显而易见。

## 这些事件之间的联系

本周发布中有一个共同方向，从任何单一标题来看都不明显。所有这些举措都在增加前沿能力的*包裹*，而非原始能力本身。

Mythos 是被保留决策包裹的前沿能力。GPT-5.4-Cyber 是被身份验证包裹的前沿能力。Deep Think 在开放式科学中是访问受控 API 包裹的前沿推理。Robotics-ER 1.6 是一个规划模型包裹着独立的执行模型。Autoresearch 是被编码智能体循环包裹的前沿训练能力，该循环强制执行预算纪律。

贯穿这五个的隐含论点是：2026年真正有趣的工程问题是包装。能力已经足够高，以至于如何暴露它的问题现在成了真正重要的决策。这与2024年不同，当时竞赛是产出最强的原始能力；也与2025年不同，当时竞赛是尽可能广泛地分发那个能力。实验室通过4月的发布告诉你：接下来的一年是谁能建最好的容器。

对于任何在这些模型之上编写智能体或基础设施代码的人，影响是直接的：假设 API 表面是主要会变化的东西，而非背后的模型。假设认证和访问控制层将和提示一样重要。假设最干净的架构会将推理循环与执行循环解耦，因为现在每个实验室都以某种形式拥有这个解耦的某个版本。

能力曲线没有停止移动。但本周的发布表明，治理和基础设施曲线刚刚开始更快地移动。
