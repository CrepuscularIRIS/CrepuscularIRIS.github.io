# One Polyp Identifies All

## 一句话摘要

利用 SAM 的级联先验与迭代提示演化完成一次性息肉分割——一项面向临床落地的医学影像实用进展。

## 为什么这篇值得读

医学分割模型通常需要**数百张标注样本**才能覆盖一种病灶。结肠镜数据集规模小、息肉形态差异大、内镜视频标注成本高。Mao 等人选择绕开这条死胡同：把 SAM 当作小样本学习者，**仅用一个已标注息肉**作为先验，就能驱动整段病例的分割。这不是理论炫技，而是对「标注瓶颈阻碍基础模型临床落地」这一现实问题的直接回应。

第二个值得关注的点是架构上的务实。作者没有在全参数级别微调 SAM 的庞大权重，而是**冻结 SAM、操作提示空间**。级联先验堆叠空间与语义线索；迭代提示演化逐帧精炼。模型学会的是「提出更好的问题」，而非「重写内部答案」。

## 核心方法（3 分钟版）

SAM 通过**提示**（点、框或掩码）驱动分割。一次性息肉分割的难点在于：单个示例息肉必须泛化到形状、大小、光照条件完全不同的新息肉。

Mao 等人设计了**级联先验管线**：

1. **空间先验** —— 一次性掩码锚定粗略感兴趣区域。
2. **语义先验** —— 从示例息肉提取的特征引导 SAM 编码器，在目标帧中锁定息肉纹理。
3. **迭代提示演化** —— 第 *t* 步输出的掩码成为第 *t+1* 步的提示，由轻量修正网络微调，在欠分割或过分割时给出微调推力。

核心洞察在于**可组合性**。每个先验单独看都很弱；串联后形成反馈闭环，在不更新 SAM 冻结参数的前提下收紧边界。这让方法保持快速，同时避免在小数据集上过拟合。

## 局限与未回答问题

- **源信息中无具体局限。** 基于方法设计的预判，待全文验证：
  - **平坦型锯齿状腺瘤**的表现如何？这类息肉扁平、视觉对比度低，一次性先验可能无法捕捉足够纹理变化。
  - 长视频中的**时间漂移**：迭代演化假设帧间相似。镜头突然回撤或肠道准备 artifacts 可能打断提示链。
  - 修正网络虽小，但仍需**一定训练数据**。作者声称「一次性」；此处「零」与「一」的精确边界值得审视。
