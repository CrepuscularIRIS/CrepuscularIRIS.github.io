## 一句话摘要

Lim 等人在 CLIP 视觉变换器上训练了一个稀疏自编码器 PatchSAE，让研究者得以观察哪些视觉概念（形状、颜色、语义）在提示调优中被重新连线——答案令人警醒：几乎没有内部概念真正改变；性能提升来自对已有概念的重新路由。

## 为什么值得花时间

基于提示的适应方法已成为 CLIP / 视觉-语言模型 pipeline 中的默认操作。冻结骨干网络，添加几个可学习 token，你的猫分类器就能检测狗了。从业者一直乐于把这当作黑箱使用——能跑就行。

这篇论文把这个黑箱撬开了。通过在 CLIP ViT 的隐藏激活上训练稀疏自编码器，Lim 等人将每个 patch 的表征分解为人类可解释的视觉概念（如"红色""圆形""像狗"），并标注每个概念在图像中哪个位置被激活。然后对比提示适应前后的概念图。

最冲击人的发现是：适应后模型的内部词汇表几乎不变。同样的概念存在；同样的 patch 激活它们。不同的是哪个 patch 映射到哪个概念——是**选择性重映射**，而不是改写。这对任何想预测某个适应方法是否能泛化、是否会静默失败、或是否引入偏置的人都有直接意义，因为你现在可以追溯连线变化，而不只是观察输入-输出行为。

简而言之：如果你曾好奇提示调优的 CLIP 究竟是在学习新的视觉基元，还是只是在重新分配已有的概念，这篇论文给出了第一个严格答案。

## 核心方法（3分钟版）

整个 pipeline 分两个阶段。

**阶段一：PatchSAE 训练。** 作者在 CLIP ViT-B/16 的残差流激活上训练稀疏自编码器。稀疏意味着损失函数驱动大部分维度为零，让每个潜在单元充当独立的"概念检测器"。他们通过探测单个潜在单元是否对应可识别的视觉特征（颜色、形状、物体类别）来验证可解释性。Patch 级空间标注告诉他们每个概念在图像中的**哪个位置**被激活。

**阶段二：跨适应的概念图对比。** 他们对四个已建立基于提示的适应方法（CoOp、KgCoOp、PDA、PDA++）分别应用到一个下游任务（主要是细粒度分类基准）。对每个适应模型，用 PatchSAE 运行同样的图像集，然后对比：（a）哪些概念被激活，以及（b）哪些图像 patch 激活了哪些概念——与冻结预训练模型对比。

关键问题不是"新概念是否诞生？"，而是"已有概念是否被重新分配？"

## 关键结果

- PatchSAE 从 CLIP ViT 中提取可解释的视觉概念（形状、颜色、语义），并附带 patch 级空间标注
- 适应模型与原始模型相比，单个概念的激活模式变化极小
- 大部分适应收益来自对已有概念的重新路由，而非新视觉基元的出现
- 研究揭示了最先进的基于提示适应技术如何改变输入到概念的关联——重映射是选择性的，集中在特定概念类别上

## 局限与未回答的问题

- 来源中未报告具体数值结果（如概念重映射百分比、相关系数等）
- 研究聚焦于 CLIP ViT-B/16；更大的模型或不同架构是否呈现相同的选择性重映射模式仍有待探索
- 工作未涉及微调或 LoRA 类权重更新方法，仅限于基于提示（冻结骨干）技术
- 从概念图漂移预测适应失败模式一说有暗示，但未系统论证
