# 梯度外推：一种无需偏置标签的去偏表示学习方法

**原文标题**: Gradient Extrapolation for Debiased Representation Learning  
**作者**: Asaad et al. | **会议**: ICCV 2025 | **年份**: 2025  
**链接**: [OpenAccess](https://openaccess.thecvf.com/content/ICCV2025/html/Asaad_Gradient_Extrapolation_for_Debiased_Representation_Learning_ICCV_2025_paper.html)

---

## 一句话摘要

这篇论文提出**梯度外推**——一种在训练阶段直接干预优化轨迹、将其推过偏置最小值点的方法，从而让模型在不依赖任何显式偏置标签的情况下，学习到不受伪相关污染的表示。

---

## 为什么选这篇

**去偏学习通常是一个数据标注问题。** 现有方法大多假设你能标注出偏置属性（肤色、背景纹理、性别线索等），然后通过重采样或对抗训练将其剔除。这个假设在实际部署中很难成立：偏置标签昂贵、可能涉及隐私，而且往往不完整。

Asaad 等人把问题翻转过来：*如果仅利用训练动态本身就能去偏呢？* 答案是梯度外推——在优化器最容易陷入伪相关的时刻，给它一个向外的推力。如果这个思路成立，它将消除公平表示学习在工程落地上的一个核心障碍。

第二个值得关注的原因是**简洁性**。这不是一个新架构，也不是一个多阶段流水线，而是一个单一的训练时修改。这种克制的方案通常意味着更容易复现、消融实验更清晰，也更容易被社区采纳。

---

## 核心方法（3 分钟版）

### 问题的一幅画面

标准的经验风险最小化（ERM）寻找在训练集上平均损失最低的参数。但当数据集中存在**伪相关**时——比如所有"骆驼"都出现在沙漠背景上——ERM 会欣然将背景吸收为特征。模型学到"沙子 = 骆驼"，遇到雪地里的骆驼就失效。

### 直觉：走过陷阱

Asaad 等人观察到，**偏置最小值通常在训练早期就被到达**。模型会先抓住简单、虚假的线索，然后才慢慢学到真正的概念。他们的关键动作是：

> **将梯度更新外推到经验风险最小值之外**，仿佛优化器正在一个去偏后的分布上继续训练。

具体来说，他们不是在损失最低点停下来，而是计算"再往前走一步"的梯度方向，并朝那个方向迈步。效果是**越过偏置的吸引 basin**，落到一个真实信号占主导的参数区域。

### 实践中的做法

论文将这一思想形式化为对标准梯度更新的修改。常规更新是：

```
θ_{t+1} = θ_t - α ∇L(θ_t)
```

他们改为外推：

```
θ_{t+1} = θ_t - α ∇L(θ_t) + β * extrapolation_term
```

其中外推项估计的是一个假设的去偏分布上的梯度方向。系数的选择保证优化器不会发散，但足以逃出伪相关的吸引子。

这一思路在概念上接近**锐度感知最小化（SAM）**和 ODE 文献中的**外推优化**，但目标不同：这里不是为了泛化或加速收敛，而是为了**消除偏置**。

## 局限与未回答的问题

**1. 外推项的校准需要精细控制。**  
外推太远会导致训练崩溃；外推太少则偏置残留。论文可能提供了启发式规则或超参数调度，但其在不同数据集上的鲁棒性仍是开放问题。

**2. 当偏置与真实信号深度纠缠时，方法是否仍然有效？**  
梯度外推假设偏置最小值是一个"浅层"吸引子，可以被越过。但在某些领域（医学影像、特定公平性场景），伪相关可能与真实信号深度耦合。方法的失效模式尚未被完全刻画。

**3. 来源笔记中未提及代码或复现细节。**  
在官方仓库或附录被检查之前，建议将本方法视为有前景但待验证。

## 延伸线索

- **IRM / V-REx**（Arjovsky et al., 2019; Krueger et al., 2021）：不变风险最小化及其变体——学习丢弃虚假环境信号的经典路线。Asaad 等人的方法是训练动态的替代方案，无需显式惩罚项。
- **SAM**（Foret et al., 2021）：锐度感知最小化——另一种修改梯度以寻找平坦极小值的技术。外推机制在精神层面与之相关，但优化目标不同。
