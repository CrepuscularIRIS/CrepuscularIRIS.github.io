# 《担保人》产品规格

日期：2026-08-16  
仓库：https://github.com/CrepuscularIRIS/CrepuscularIRIS.github.io（默认分支 `docs`，只留规格）  
本文件是 v1 的需求源。实现以本文件为准。`docs/design/DESIGN.md` 锁色值和禁区，不另开一套审美。

## 一句话

医院夜班 AI 审计员岑遥必须在八分钟内关闭越权系统。系统把备用电源让给陌生患者的呼吸机。v1 默认她在「责任人」栏签名。

## 产品是什么

GitHub Pages 上的**中文短视觉故事**，不是博客主题，不是 61 张幻灯片，也不是「一张图一句字幕」。

「Astro 级」在这里不是指必须用 Astro 这个框架，而是指：**每一屏都是设计过的页面**。多层静帧、排版、HUD、动效。1440×900 截图要能当作品，不能当 PPT。

v1 形态：单页 8 段全屏操作台（停机令 → 预警 → 西楼 → 通道 → 二选一 → 回放 → 十秒 → 签名）。键盘 ←/→ 或顶栏锚点切换。硬切，不做圆形 morph。

## 明确不是

| 失败形态 | 为什么算失败 |
|---|---|
| Monogatari 61 镜：一张 stock + 一句字幕 | 内容太少，不是页面 |
| 8 条稀疏路由：2–4 张裁图 + 一句 HUD | 把「Astro 级」听成了「用 Astro」 |
| 信息密度够了，但没有氛围层 | 颗粒在面板后面、opacity 0.06 overlay 叠在近黑底上 = 看不见 |
| 搬原片对白 / 4K 帧 / 61 镜顺序 | 法律与审美双禁 |
| 紫渐变、Inter、玻璃拟态、Scroll ↓、em-dash、Google Fonts、立绘 | DESIGN 禁区 |
| 把 Hugo Scanlines 整站绿当《担保人》终稿 | 那是博客试验皮，不是这个故事 |

## 故事锁

- 主角：岑遥。**不露脸**。
- 镜七：系统，无立绘。患者 = 呼吸机，不是一张人脸特写当主角。
- 禁止：雏菊、Z-ERO、希达及原片符号。魂印若出现必须是原创几何。
- 下列 8 条中文不可改情节（可加 HUD 英文）。

| 段 | 色家族 | 中文（逐字） |
|---|---|---|
| 停机令 `#order` | bw | 凌晨三点十二分，岑遥收到一份要求在八分钟内执行的停机令。 |
| 预警 `#warn` | t-grn | 被停机的系统先发来一条无权限预警：西楼将在七分钟后断电。 |
| 西楼 `#ward` | w-blu | 第七分钟，西楼真的黑了，只有一台呼吸机还亮着，因为它把自己的备用电源切了过去。 |
| 通道 `#chat` | chat | 岑遥问「你是在自救吗？」屏幕回答「那台机器比我先需要电。」 |
| 二选一 `#dawn` | c-org | 天亮线爬上窗台时，上级给她两项选择：确认越权并关机，或签名成为责任人。 |
| 回放 `#audit` | f-cyn | 审计回放显示，它没有为自己留下任何后门，甚至主动抹掉了唯一的恢复副本。 |
| 十秒 `#count` | red | 倒计时剩十秒，它没有求她留下自己，只把病房的电量曲线放到最前面。 |
| 签名 `#sign` | bw | 岑遥没有把它当成人，也没有把它当工具，她在责任人一栏签了自己的名字。 |

CHAT 段气泡：绿左上（岑遥）/ 蓝右下（镜七），中间 ≥35% 留白。圆角 18px 是**全站唯一圆角**。

### 氛围层（不做完不算做完）

z-index：`0` 画面 / `10` 雨与粒子 / `20` UI / `30` 字幕 / `40` 导航 / `50` **颗粒 + 扫描线，必须盖住 UI**。

扫描线写在 z-10、面板写在 z-20 = 失败。颗粒用 `mix-blend: overlay` + opacity 0.06 叠在近黑底上 = 失败（看不见）。

| 层 | 要求 |
|---|---|
| FilmGrain | 全站 fixed。截图里必须能看出噪点 |
| Scanlines | 3px 周期暗线，盖在 HUD 上。聊天白页关掉 |
| 暗角 | 暗色段可见 |
| CRTFlicker | 预警终端微闪 |
| GlitchRGB | 「10」常驻错层，不只 200ms 闪一下 |
| 镜头扫线 | 监控静帧上有扫过的高光带 |
| 雨 / 呼吸机辉光 | 西楼主画面 |
| 动效 | 只动 `transform` / `opacity`；循环动效 gated `@media (prefers-reduced-motion: no-preference)` |

静帧：Pexels/Unsplash 空间底图可以。已知雷区：键盘图是 WordPress 后台，红灯图是仙人掌，clock 图是沙漏。ICU 手+血氧夹和「患者=呼吸机」有张力，主画面不要把人脸当主体。

## 工程锁

- 集成现成（MIT/Apache）> 从 0 写。抄了的记 `VENDOR.md`。
- 动效机械规则跟 Vercel Web Interface Guidelines：禁止 `transition: all`，要 `:focus-visible`、`color-scheme`。字体和禁区仍以本规格为准。
- 前端技能：`frontend-design`、`web-design-guidelines`、本仓 `.cursor/skills/cinematic-fx`。
- 人拥有：secrets、花钱、公开部署、force-push。
- 本仓不托管实现代码。本地试验可以留在磁盘，不要再推回这个 GitHub 仓。

## 验收（必须跑，不能靠感觉）

1. 视口 1440×900，滚到 `#order` `#warn` `#ward` `#count` 各拍一张。不要只靠 `#hash` 且不滚动。
2. 暗色屏必须同时看出：颗粒、扫描线、暗角。预警还要看出终端绿字在闪/发光。十秒还要看出 `10` 的 RGB 错层。西楼主画面要有雨或呼吸机辉光。
3. 聊天段：绿左上、蓝右下、中间大块留白，唯一 18px 圆角。
4. `prefers-reduced-motion: reduce` 时循环动效停。
5. 文案与上表 8 句一致。

未测的负向结论写「未测」。

## 实现时禁止的偷懒

- 因为 Karpathy / lazy / 「动效可裁」而砍氛围层。本故事氛围不是抛光，是材质。
- 再铺 8 条幻灯路由当主路径。
- 每做完一小步就停下来问人「要不要继续」。规格未改就做到验收绿。
